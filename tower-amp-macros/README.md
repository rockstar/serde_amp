tower-amp-macros
==

![crates.io](https://img.shields.io/crates/v/tower-amp-macros.svg) ![docs.rs](https://docs.rs/tower-amp-macros/badge.svg)

The `#[command]` attribute macro for [tower-amp](https://crates.io/crates/tower-amp).
Depend on tower-amp, which re-exports it; this crate is not meant to be used
on its own.
